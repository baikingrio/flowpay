# Flowpay

像登录普通 App 一样进入 Monad 世界。

**Google / GitHub 一键注册 → 转账与交易用 Face ID 确认 → 无种子短语、自托管。**

> Flowpay — 像流水一样顺畅的链上支付与账户体验。
