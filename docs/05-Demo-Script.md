# Demo Script（评委演示脚本）— Passkey-first with Checkout Hero

**总时长建议**：3–4 分钟

### 开场（30 秒）
"当前链上最大的门槛是账户体验——种子短语、钱包扩展、复杂概念。  
FlowPay 用 Mera 作为整个账户层：用户只需一次 Face ID，就能拥有自托管账户。  
今天我重点演示**双设备收款结账**——商家和顾客，两台手机，实时 USDC 到账，像扫码支付一样流畅。"

### 演示流程（2–2.5 分钟）

1. **One-prompt 开户（顾客设备）**  
   "顾客打开 FlowPay → 点击『立即开始』→ 一次生物识别 → 完成。  
   账户已通过 Mera 派生，直接显示地址和余额。没有邮箱，没有助记词，没有第二次提示。"

2. **商家启动收款（商家设备）**  
   "现在切到商家设备。商家进入收银台，输入金额（比如 10.00 USDC）→ 点击『收款』→ 生成二维码。  
   这是一个 EIP-681 ERC-20 转账 URI，包含收款地址、代币合约、金额、链 ID。"

3. **顾客扫码支付（顾客设备）**  
   "顾客用手机扫码（或点击付款链接）→ FlowPay 自动解析 URI，填充收款地址和金额。  
   确认 → 交易发送到 Monad。因为已有 Signing Session，整个过程 prompt-free，无需再次刷脸。"

4. **商家收款到账反馈（商家设备）— Hero Moment**  
   "Monad 300ms 出块 + 1s 最终性。商家这边开始轮询链上 USDC Transfer 事件。  
   几秒后 → **绿色圆圈放大动画 + ✓ + 音效** → 『收款成功 10.00 USDC』。  
   商家设备本地账本立即更新，显示今日流水。"

5. **Session 连续操作（顾客设备）**  
   "在会话有效期内，顾客可以连续再做一笔操作——比如快速 Swap MON ↔ USDC，或再付款一次——都无需重复刷脸。  
   会话过期后，系统会清晰提示并要求重新验证。"

6. **Stateless Test（关键加分）**  
   "现在我清除顾客设备的 localStorage，或者用无痕/另一台设备打开。  
   再次点击『用 Face ID 继续』→ 同一 Passkey → 账户完整恢复，余额、地址完全一致。  
   身份和访问能力完全从 Passkey 重建，不依赖本地敏感存储。"

### 收尾（20–30 秒）
"FlowPay 同时服务主赛道和 Mera Bounty：  
- **双设备结账**：商家二维码 → 顾客扫码 → 商家到账，全程真实链上交易，不是演示计时器。  
- **One-prompt 开户**：一次 Face ID 完成账户派生，Mera 是整个账户层。  
- **Stateless 恢复**：清除本地数据后，同一 Passkey 完整找回账户。  
谢谢。"

### 备用问答要点

- **为什么不用社交登录作为主入口？**  
  为了严格满足 Mera 的 One-prompt 和「Mera is the entire account layer」要求，同时通过 Stateless Test。  
  （GitHub OAuth 绑定是可选辅助路径，不在评委演示中出现。）

- **私钥存在哪里？**  
  通过 WebAuthn PRF 在用户认证器中派生，签名时仅在内存短暂出现，无项目方托管。

- **Session 多久过期？**  
  当前设计为 15 分钟无交互自动过期，高风险操作可强制重新验证。

- **Gas 赞助 / ERC-4337？**  
  当前范围延后。顾客需要少量 MON 支付 Gas（水龙头可领取）。  
  演示中顾客已提前从水龙头领取 MON，保证结账流畅。

- **商家轮询会不会漏单？**  
  从二维码生成时刻起往前回溯 2000 区块，匹配收款地址 + 代币 + 金额 + 时间窗口（5 分钟）。  
  真实链上日志查询，不是模拟，不会漏。

- **换设备怎么办？**  
  同一 Passkey（iCloud Keychain / Google Password Manager 等）即可在新设备完整恢复，我们刚演示过。
