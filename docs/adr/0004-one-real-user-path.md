# One real user path; no judge-only shortcut

Funding, One-prompt, First Payment, and Stateless recovery are the same path for everyone. A new Account with zero MON shows the address and an external Faucet; the First Payment CTA stays disabled until the Ledger shows a balance. We do not pre-fund, auto-send from a treasury, or keep a separate recover-into-funded-account flow for judges. Time-to-first-transaction includes waiting on the Faucet when the Account is empty.
