# 产品演示视频脚本（≤3 分钟）
目标成片：2 分 20 秒～2 分 50 秒。竖屏或横屏均可；必须是真机可运行产品，不要 PPT。

## 拍摄准备
- 两台支持 Passkey PRF 的真机（商家一台、顾客一台）
- 打开 https://flowpay-tau-sand.vercel.app
- 顾客端备好测试网 MON（Gas）与 USDC
- 提前走通一遍；录屏建议系统原声 + 你旁白，或后期叠旁白

## 分镜与旁白

【0:00–0:20｜落地页】
画面：打开生产站落地页，滚动「怎么用」三步（Passkey → 当面收款 → 确认到账）。
旁白：Flowpay 让当面收 USDC 像扫码支付。账户层是 Mera Passkey——无种子短语、无钱包扩展、无托管。

【0:20–0:45｜开户】
画面：顾客机点击「用 Face ID / 指纹开始」，完成生物识别，进入首页看到地址。
旁白：一次面容或指纹，账户就好了。这是 One-prompt onboarding。

【0:45–1:40｜双设备收款｜核心】
画面：商家打开收银台，输入例如 1 USDC，生成二维码；顾客扫码或打开付款页，确认金额，Passkey 支付；商家端出现到账成功与提示音，今日流水多一笔。
旁白：商家输入金额出码，顾客扫码付款。到账按链上转账匹配，不是假成功。老板能直接看今日流水。

【1:40–2:05｜导出】
画面：点击导出 CSV，打开文件一眼看到金额、状态、交易哈希。
旁白：流水可以导出对账，哈希能在浏览器核对。

【2:05–2:35｜Stateless 或 Session 二选一】
推荐 Stateless（加分）：设置 → 清除本机数据 → 回落地页 → 同一 Passkey → 同一地址回来。
旁白：清掉本机数据，只凭同一枚 Passkey 还能找回同一地址。身份与访问能力不依赖本地机密存储。

【2:35–2:50｜收尾】
画面：回到收银台或落地页 Logo。
旁白：Flowpay：Passkey 账户层 + 当面 USDC 收银。演示地址在简介。谢谢。

## 不要拍
- 不要演示 Swap 当卖点
- 不要声称已有 Gas 赞助或主网
- 不要念代码或翻 PPT
