## 结构旁白（可直接念）

我是 Quinn，Flowpay 的构建者。

链上支付长期卡在两件事：普通人过不了助记词和钱包门槛；而一些本来就要收 USDC 的线下场景，又缺少像扫码一样顺手的收银工具。

Flowpay 做的是交叉点：用 Mera 把账户变成一次 Face ID / 指纹；用商家出码、顾客扫码，把 USDC 当面收款做成可演示、可对账的闭环。我们不追求先做全能钱包，先把收银主线做扎实。

我做这件事，是因为只有账户层足够简单、收款结果足够可核对，稳定币才有机会走进真实摊位，而不是停在演示幻灯片里。黑客松提交的就是这套正在打磨的产品本身。

欢迎体验：flowpay-tau-sand.vercel.app。
